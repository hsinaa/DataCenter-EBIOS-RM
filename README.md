# DataCenter EBIOS RM

**DataCenter EBIOS RM** est un projet d’analyse des risques en **cybersécurité** dans un datacenter.

## Objectifs

Le projet consiste à :

* définir le périmètre du datacenter ;
* identifier les éléments importants du système ;
* identifier les risques et les menaces ;
* construire des scénarios d’attaque ;
* identifier les mesures de sécurité ;
* proposer un plan pour réduire les risques ;
* représenter l’architecture du datacenter.

## Les 5 ateliers EBIOS RM

| Atelier       | Objectif                                                                     |
| ------------- | ---------------------------------------------------------------------------- |
| **Atelier 1** | Identifier les valeurs métier, les biens supports et les événements redoutés |
| **Atelier 2** | Identifier les sources de risque et leurs objectifs                          |
| **Atelier 3** | Construire les scénarios stratégiques                                        |
| **Atelier 4** | Construire les scénarios opérationnels                                       |
| **Atelier 5** | Définir les mesures de sécurité et le plan de traitement                     |

## Risques étudiés

L’analyse concerne principalement :

* la **confidentialité** des données ;
* l’**intégrité** des données et des systèmes ;
* la **disponibilité** des services ;
* la protection des **comptes et accès privilégiés** ;
* la sécurité des **machines virtuelles et infrastructures** ;
* la **sauvegarde et récupération des données** ;
* la continuité des services.

## Livrables

Le projet comprend :

* un document de cadrage ;
* l’analyse des valeurs métier ;
* l’identification des biens supports ;
* l’analyse des événements redoutés ;
* l’identification des sources de risque ;
* les scénarios stratégiques et opérationnels ;
* les mesures de sécurité ;
* le plan de traitement des risques ;
* la cartographie du datacenter.
