# DataCenter EBIOS RM

Risk management project based on the EBIOS Risk Manager methodology.

## Objective

L’objectif de ce projet est de réaliser une analyse de risques de sécurité du système d'information du datacenter en utilisant la méthode EBIOS Risk Manager.
